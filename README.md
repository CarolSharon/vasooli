# Vasooli

Vasooli is an AI revenue-recovery system for failed payments, abandoned
checkouts, failed subscriptions, overdue invoices and promises to pay.

## Status

Day 1: data and platform foundation.

## Data disclosure

This repository combines Razorpay Test Mode events with synthetic customer,
history, consent, invoice and recovery context. Data provenance is recorded
explicitly. Synthetic data is not presented as production merchant data.

See [EXPERIMENT.md](EXPERIMENT.md) for the frozen evaluation protocol.
